## Keeping the docs current

When a change makes something in `docs/ARCHITECTURE.md` wrong or incomplete,
update it in the same commit. That covers added, removed or renamed files,
routes, actions or components; schema, RLS or auth changes; and new conventions.
Don't update it for changes inside a file that leave its role the same, such as
styling, copy or bug fixes. Keep it a map, not a copy of the code.
